# Mon site vitrine

## Description
 
Site vitrine d'un artisan menuisier : presentation de l'atelier, galerie
de realisations et formulaire de contact. Concu pour etre leger, rapide
et consultable depuis un telephone.

Site **100 % statique**, sans base de donnees, en *HTML, CSS et
JavaScript natif*. ~~Version WordPress abandonnee~~.

## Installation
 
```bash
git clone https://github.com/mon-compte/mon-site-vitrine.git
cd mon-site-vitrine
```

## Utilisation
 
- ouvrir `index.html` directement dans un navigateur ;
- ou lancer l'extension Live Server depuis VS Code pour le rechargement
  automatique a chaque enregistrement.
 
> Astuce : avec Live Server, la page se recharge seule des que vous
> sauvegardez un fichier.

## Stack technique
 
- HTML5
- CSS3 (Flexbox et Grid)
- JavaScript ES6, sans framework ni dependance
